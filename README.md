## Sobre mí

Soy desarrolladora **Full-Stack con foco en Frontend**. Diseño y construyo productos digitales claros, responsivos y funcionales, cuidando tanto la experiencia visual como la integración con APIs y bases de datos.

- 📍 San Luis, Argentina — disponible para trabajo remoto.
- 🎯 Busco oportunidades como **Frontend Developer Jr.** o **Full-Stack Developer Jr.**
- ✨ Me interesan las interfaces con personalidad, el código mantenible y los detalles que mejoran la experiencia.
- 🤖 Exploro automatización e inteligencia artificial aplicada a productos digitales.
- 🌱 Formación Full-Stack en Soy Henry y aprendizaje continuo en desarrollo web.
